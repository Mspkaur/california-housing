# California Housing Price Prediction

This project implements a machine learning model to predict housing prices in California using the California Housing dataset.

## Features

- Data preprocessing and scaling
- Random Forest Regression model
- Model performance evaluation
- Feature importance visualization

## Setup

1. Install the required packages:
```bash
pip install -r requirements.txt
```

2. Run the model:
```bash
python housing_model.py
```

## Output

The script will:
- Train a Random Forest model on the California Housing dataset
- Display model performance metrics (RMSE and R² score)
- Generate a feature importance plot saved as 'feature_importance.png'
